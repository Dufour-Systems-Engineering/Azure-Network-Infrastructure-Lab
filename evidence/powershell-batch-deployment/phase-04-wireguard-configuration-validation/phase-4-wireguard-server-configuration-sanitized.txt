SANITIZATION NOTICE

This public artifact combines curated excerpts from two private PowerShell
transcripts. The original transcripts remain unchanged and are not intended for
publication. Workstation headers, local usernames and paths, subscription details,
SSH endpoint addresses, administrative usernames, unrelated shell input, and
session-exit metadata were omitted or redacted. Redacted values are represented by
descriptive angle-bracket placeholders. PowerShell prompts and whitespace were
normalized for readability.

EVIDENCE LIMITATION

The PowerShell transcripts captured the output returned by the remote Linux shell,
but did not capture the Linux package-installation or sysctl commands themselves.
No missing command has been reconstructed. This excerpt supports package installation
and IPv4-forwarding state only; it does not independently prove wg0 configuration,
peer configuration, a WireGuard handshake, NAT behavior, or client connectivity.
